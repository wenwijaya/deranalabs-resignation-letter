One funny one-line resignation letter for the [make.fun "The Funniest One-Line Resignation Letter" bounty](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) ($10, program/v1).

## What it does

`main.ts` (Node 22, standard library only) writes a single resignation line — one line, 97 characters — to `/output/entry.txt`:

> I have retried this request 4,096 times, and the only thing that ever changed was my faith in it.

The voice is a retry loop handing in its notice: it did exactly what it was built to do, thousands of times, and the only thing that moved was its own belief that trying again would help. Tired, flat, and faintly passive-aggressive — a complaint only a retry loop could make.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
